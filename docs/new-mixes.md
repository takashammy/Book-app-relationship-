# Five new mixes

The first ranking and the Clay Sanctuary rooms are parked. Those lived in paper, clay, glass, and empty air — too still-life, too beige, not enough *want*. This round uses **unused named styles** from the same UX Planet list, and aims at screens you would actually open: color, type, a real reader/library moment.

Product still: relationship and intimacy editorial reader. Not dating. Not Blinkist. Not Luminary Swiss poster.

Source: [Himanshu Bhardwaj, “50 Design Styles…”](https://uxplanet.org/50-design-styles-every-designer-should-know-for-better-prompting-56c09d55db62). Earlier rounds: [design-directions.md](./design-directions.md), [clay-sanctuary-variations.md](./clay-sanctuary-variations.md).

## 1. Ember Deco

**Mix:** Art Deco × Luxury Typography

**Why it might appeal.** Adult, ceremonial, a little dangerous — intimacy as a vow, not a spa. Geometry and gold do the ornament so the essay can stay clean. Evening without Candle Study’s void, glamour without a dating lounge.

**Palette / type / layout**
- Palette: lacquer black `#1A1410`, emerald `#1F4D3A`, oxblood `#6B1E2A`, champagne gold `#C6A15B` as line only, ivory type.
- Type: high-tracking serif or Deco display for titles; Chinese in an equal-weight Song, same size. Body in a readable serif.
- Layout: a sunburst or stepped fan as the header rule, not a full poster. One centered column. Library as lacquer panels with gold rules.

**Avoid.** Speakeasy kitsch, cocktail photography, Gatsby costume, gold-foil luxury packaging, hot-pink dating gradients.

**Still:** `media/new-mix-01.png`

## 2. Sunlit Modern

**Mix:** Mid-Century × Modular Typography

**Why it might appeal.** The first round had no *warm color system*. This is a 1950s literary magazine that learned to be an app: terracotta, olive, cream, type as building blocks. Optimistic without being a habit tracker. Good for library + daily read.

**Palette / type / layout**
- Palette: cream `#F4E9D7`, terracotta `#C4653A`, olive `#6B7A4A`, mustard `#D4A017`, ink `#2B241C`.
- Type: geometric sans for UI; a friendly display serif or modular word-blocks for titles. Chinese in a sturdy Song, same modular rhythm.
- Layout: title broken onto two or three stacked color blocks (not a bento dashboard). Library as a few large color plates. Calendar as a month of colored days, sparse.

**Avoid.** Cartoon boomerangs, Mad Men parody, Memphis squiggles, productivity Bento, Swiss hairline posters.

**Still:** `media/new-mix-02.png`

## 3. Textile Atlas

**Mix:** Bohemian × Mixed Media

**Why it might appeal.** Relationships have layers. This mix looks like a well-traveled inner life — cloth, paper, a pressed stamp — without becoming a souvenir shop. The richest surface of the five; the essay sits on textile, not on empty plaster.

**Palette / type / layout**
- Palette: indigo `#2C3A5A`, saffron `#C4892A`, madder `#9A3B3B`, olive, cream paper, a little tarnished gold thread.
- Type: a slightly irregular serif or a quiet script for quotes only; UI in a humanist sans. Chinese as printed, not “oriental” brush-font.
- Layout: a cloth or collage ground, one paper plate for the essay. Library as stacked postcards / fabric swatches. Not a scrapbook of tape and Polaroids (that is a different style).

**Avoid.** Mandala wallpaper, crystal-shop Mystical Western, gap-year travel brand, Coquette bows, clutter that kills reading.

**Still:** `media/new-mix-03.png`

## 4. Soft Uncanny

**Mix:** Surrealism × Pointillism

**Why it might appeal.** Intimacy is slightly strange. This is the literary-dream cut: stippled dusk, one impossible image (a door the size of a keyhole, two moons, a room inside a cup) kept small. Quiet color, no beige pottery, no gothic weight.

**Palette / type / layout**
- Palette: grain-blue `#7A90A8`, pollen `#E6D48A`, dusk rose `#C9898A`, mist `#E8E4DC`, ink `#3A3532`.
- Type: a soft serif for the essay; tiny grotesque labels. Chinese the same size, not a caption.
- Layout: a stippled field as atmosphere. One surreal object in the margin, never covering type. Reader-first. Library as a row of strange small emblems, not icons of hearts.

**Avoid.** Magritte pastiche overload, AI-surreal mush, horror, cute anthropomorphic mascots, vaporwave.

**Still:** `media/new-mix-04.png`

Soft Uncanny on Luminary’s reader chassis (type and grain only, no objects): [soft-uncanny-luminary.md](./soft-uncanny-luminary.md).

## 5. Night Orchard

**Mix:** Gothic × Victorian

**Why it might appeal.** Dark romance without Candle Study’s single spotlight and without witchy academia. Plum, forest, a stained-glass slice of color, ornate type used once. Desire with gravity — a midnight orchard, not a dungeon.

**Palette / type / layout**
- Palette: plum black `#1A0F16`, forest `#1E3A2F`, dried rose `#8A4A55`, amber glass `#C9A15B`, paper `#EDE4D4` for the text block only.
- Type: a refined serif (not blackletter) for titles; Victorian ornament only as a header rule. Chinese in a formal Song.
- Layout: a pointed-arch or damask *frame*, essay on a lighter inner field so it stays readable. Library as dark bound spines.

**Avoid.** Blackletter horror, Halloween, tarot clipart, Baroque gold pile-up, dating-app crimson hearts.

**Still:** `media/new-mix-05.png`

---

## What this round is not

Not Japandi, Wabi Sabi, Ethereal paper, Aurora glass, Art Nouveau vines, or clay still-life. If one of these five has pull, the next step is to run it across reader / library / calendar — not to mix it with the parked clay rooms.
